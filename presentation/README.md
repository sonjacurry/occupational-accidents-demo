# Project Presentation

This folder contains the presentation created for the Occupational

Accidents in Finland analytics project.

## Presentation

The presentation summarises:

- Project objectives

- StatFin data source

- PXWeb API extraction

- Databricks data pipeline

- Bronze, Silver and Gold architecture

- Industry hierarchy modelling

- Power BI report structure

- Main analytical findings

- Project limitations

- Future development opportunities

## LaTeX Source

The editable LaTeX source is available in the [`src`](src/) folder.

The presentation was developed in Overleaf using the Beamer document

class.
